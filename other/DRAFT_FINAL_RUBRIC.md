# Final Rubric  (1st Draft):
Your grade on teh final presentation will be based on whether you implement the basic requirements of this class and then whether you show mastery in your game engine and/or game.

Key:
- ✅ Implemented in class
- ☑️ Partially implemented in class
- ❌ Not yet implemented in class

# Game Engine Requirements
- ✅Correctly uses a game loop using requestAnimationFrame
- ✅Correctly uses the Scene, Game Object, Component Architecture
- ✅Correctly uses a game object hierarchy
- ✅Correctly allows for communication between components, game objects, and scenes.
- ✅Loads scenes with a SceneManager
- ✅Does not have loops/extra code in scene or game object instances.
  

# Game Requirements
## Visual
- ✅The game/engine supports drawing in world space and UI space
- ✅The game/engine supports game object scale, rotate, and translate
- ✅The game/engine supports a camera
## Interactive
- ✅The game supports keyboard and/or mouse input
- ✅The game supports multiple scenes, including a start scene
## Simulation
- ☑️There is some NPC behavior
- ✅The game/engine supports collisions and collision resolution
- ✅The game supports collision layers

# Mastery
You can do a lot of things to go above and beyond in your engine or game. Here are some ideas
- Make an extensive game
- Make a detailed game
- Make a game that feels complete
- Implement particle systems in your engine and use them
- Implement Behavior Trees in your engine and use them
- Implement Letter Boxing in your engine and use it
- etc.


# Grades
The grade for the final will be based on  this rubric as follows:

| Grade  | Expectations  |  
|---|---|
|  A | Meets the requirements and show mastery in many areas  |
|  B | Meets the requirements and goes shows mastery in some areas  |
|  C | Meets the requirements, but does not show mastery |
|  D | Meets some of the requirements, but not all  |
|  F | Fails to be meet the basic requirements  |
